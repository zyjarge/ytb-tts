# YouTube 中文配音(MVP)

一个 Chrome 扩展:将 YouTube 视频的英文字幕实时翻译为简体中文,并用 MiniMax TTS 逐句合成语音,与原画面时间戳同步播放,原声自动静音。

**技术思路**:不下载视频/音频流,只抓取 YouTube 自带字幕轨道(带时间戳文本)→ 批量机器翻译 → 逐句 TTS 合成 → 按时间戳同步播放。整条链路全部在浏览器内实时完成。

## 安装

1. 打开 `chrome://extensions`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」,选择本目录(`youtube-zh-dubbing/`)
4. 点击插件图标 →「设置」,填入以下配置并保存:
   - **MiniMax API Key**(必填,`platform.minimaxi.com` 控制台获取)
   - **Group ID**(可选,旧版账号需要才填)
   - **音色 / 语速**(默认:青涩青年音色,语速 1.0)
   - **翻译 API 地址 / Key / 模型**(默认 DeepSeek,可换成任意 OpenAI 兼容服务)

## 使用

1. 打开任意带**英文字幕**的 YouTube 视频
2. 点击播放器控制栏右侧的「中文配音」按钮(喇叭图标,与设置/全屏按钮同排;激活后变为蓝色)
3. 点击后视频**先暂停**,播放器中央显示加载浮层(转圈 + 进度文案);插件从当前播放位置开始**流式配音**:按批翻译 + 逐句合成语音,**首批缓冲(起始句起连续 3 句)就绪后自动续播**,后续边合成边播;中途某句尚未合成完成时视频会短暂暂停缓冲等待并显示加载浮层(10 分钟视频的首批等待通常在几十秒内,受 MiniMax 限流约束),已合成内容有持久缓存,**同一视频第二次点击近乎即时**
4. 配音与原画面自动对齐:句子较长时视频轻微减速、配音轻微加速(各承担一半,人耳基本无感);迟到起播的句子从尾部对齐,不丢内容
5. 再次点击「停止配音」恢复原声(缓冲期间点击可随时取消)

支持:暂停 / 拖动进度条 / 倍速播放(自动重新对齐);无英文字幕的视频会给出明确提示。
配音期间原声保持静音(调音量会被自动恢复静音,想听原声请点「停止配音」)。

## 项目结构

```
youtube-zh-dubbing/
├── manifest.json          # MV3 清单(权限最小化)
├── background.js          # Service Worker:翻译 + TTS 调度 + 缓存
├── content.js             # 页面注入:UI 按钮、字幕抓取、播放引擎集成
├── injected.js            # 注入主世界:读取 ytInitialPlayerResponse、hook 播放器带 pot 的字幕请求
├── options.html/js        # 设置页
├── lib/
│   ├── subtitles.js       # timedtext JSON3 解析、片段合并、轨道选择
│   ├── translate.js       # OpenAI 兼容翻译封装(分块、按行对应)
│   ├── minimax_tts.js     # MiniMax TTS 封装(hex 解码、限流自适应队列)
│   └── syncplayer.js      # 时间戳对齐播放引擎
└── icons/                 # 插件图标
```

## 已知限制

- **仅限英文 → 中文**:需要视频有英文(人工或自动)字幕
- **字幕借道播放器请求获取**:YouTube 对 timedtext 接口强制 pot(PO Token)校验,直接用字幕 URL 请求会返回空内容。插件通过主世界钩子捕获播放器自己的字幕请求——点击按钮瞬间会短暂开启再恢复 CC 字幕,配音期间原字幕窗口被 CSS 隐藏
- **背景音被完全静音**:MVP 不保留/分离背景音
- **单说话人**:不区分说话人,统一使用所选音色
- **合成速率受 API 限流约束**:MiniMax TTS 免费用户约 10 次/分钟、充值用户 20 次/分钟,限流触发时自动降速退避;配音管线快于限流速度时,视频会在句间短暂暂停缓冲等待。翻译与音频均有持久缓存,中断后重开或二次观看成本很低
- **仅供个人本地使用**:API Key 保存在本机 `chrome.storage.local`,切勿打包分发含 key 的插件

## API 成本估算

| 项 | 单价参考 | 一个 10 分钟视频(~150 句) |
|---|---|---|
| MiniMax TTS | 约 ¥0.002/千字符(以官方计费为准) | 约 ¥0.01~0.03 |
| 翻译(DeepSeek) | 输入 ¥0.5/百万 tokens、输出 ¥2/百万 tokens | 约 ¥0.01 以内 |

总成本极低(每次观看约几分钱量级),主要瓶颈是限流而非费用。以官方控制台计费为准。

## 自测说明

- 测试视频:任意 10 分钟以上、带英文字幕的 YouTube 演讲/课程视频(如 TED 官方频道)
- 验证场景:
  1. 点击按钮后视频立即暂停并显示加载浮层(转圈+进度),首批 3 句缓冲就绪后自动续播开口,原声静音
  2. 暂停 → 恢复、拖动进度条 → 2 秒内重新对齐
  3. 倍速 1.5x / 2x 下配音跟随(用户调速后插件不再干预视频速率)
  4. 加载期间再次点击按钮可取消加载并恢复原声续播;播放中缓冲同样显示加载浮层
  5. 无字幕视频提示「该视频无可用英文字幕」且不报错
  6. 连续播放 10 分钟无漏播/重复/乱序(控制台无未捕获异常)
  7. 同一视频第二次点击:命中缓存,几乎立即开口
